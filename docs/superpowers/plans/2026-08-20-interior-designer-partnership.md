# Interior Designer Partnership Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Not subagent-driven-development for this project — that workflow assumes commits between tasks, and this project's standing rule is that the user handles all commits/pushes themselves.)

**Goal:** Ship `/interior-designer-partnership` — a fully animated B2B landing page pitching interior designers on a standalone Design Partner Program — with a lead-capture application form, and add it to the "Business" nav dropdown.

**Architecture:** A Server Component page (`app/interior-designer-partnership/page.tsx`) holds metadata and `FAQPage` JSON-LD, and renders a sequence of dedicated "use client" section components under `components/design-partners/` — mirroring exactly how the homepage already composes `components/homepage/TrustBar.tsx`, `ArtaceJourney.tsx`, etc. A guest-friendly lead-capture endpoint (mirroring the existing Trade Program's) handles the application form; no payment, no commission-tracking automation.

**Tech Stack:** Next.js App Router, TypeScript, Tailwind CSS 4, Framer Motion (`framer-motion`, already a project dependency — confirmed existing usage in `components/homepage/TrustBar.tsx` and `components/homepage/ArtaceJourney.tsx`), Supabase (lead storage), Resend (notification email).

**Spec:** `docs/superpowers/specs/2026-08-20-interior-designer-partnership-design.md`

## Global Constraints

- No `git commit`/`git push` — the user reviews and commits/pushes everything themselves.
- No test framework — verification via `npx tsc --noEmit` and live dev-server checks on a fresh port, checking `netstat -ano | grep ":3000"` first and never touching that PID.
- Real Trust Bar numbers (from the user): **10+ Designer Collaborations**, **21+ Metro Cities Served**. The third trust clause, **100% Handcrafted, 0% Mass-Produced**, is used verbatim.

- Fully standalone program — no wiring into the existing Affiliate Program's referral-code/commission-tracking system. "Commission on referred projects" is marketing copy only; the application is a manual-review lead, exactly like Trade/Custom Order/Custom Portraits.
- Respect `useReducedMotion()` in every animated component, matching the pattern already used in `components/homepage/TrustBar.tsx` and `components/homepage/ArtaceJourney.tsx`.
- Reuse directly, do not rebuild: `components/seo/FAQSection.tsx`, `components/custom-order/ImageUpload.tsx`, `lib/api-route-handlers/upload-image/route.ts`, `lib/site.ts`'s `buildSiteUrl`.

`lib/api-route-handlers/design-partners/route.ts` (structurally identical to `lib/api-route-handlers/trade-leads/route.ts`):

```ts
import { NextResponse } from "next/server";

export const runtime = "edge";

type DesignPartnerPayload = {
  fullName: string;
  studioName?: string;
  city: string;
  projectType: string;
  email: string;
  phone: string;
  moodBoardUrl?: string;
  message?: string;
};

const SUPABASE_URL =
  process.env.SUPABASE_URL ||
  process.env.NEXT_PUBLIC_SUPABASE_URL ||
  process.env["Project URL"] ||
  "";
const SUPABASE_SERVICE_ROLE_KEY =
  process.env.SUPABASE_SERVICE_ROLE_KEY ||
  process.env.SUPABASE_ANON_KEY ||
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY ||
  process.env["Anon Key"] ||
  "";

const CONTACT_TO_EMAIL =
  process.env.CORPORATE_CONTACT_EMAIL || process.env.CONTACT_TO_EMAIL || "info@artacestudio.com";

const RESEND_API_KEY = process.env.RESEND_API_KEY || "";
const RESEND_FROM = process.env.RESEND_FROM || "";

const isValidEmail = (value: string) => /\S+@\S+\.\S+/.test(value);

const buildEmailText = (payload: DesignPartnerPayload) => {
  return [
    "New design partner application:",
    "",
    `Name: ${payload.fullName}`,
    payload.studioName ? `Studio/Firm: ${payload.studioName}` : "",
    `City: ${payload.city}`,
    `Project Type: ${payload.projectType}`,
    `Email: ${payload.email}`,
    `Phone: ${payload.phone}`,
    payload.moodBoardUrl ? `Mood Board: ${payload.moodBoardUrl}` : "",
    "",
    "Message:",
    payload.message || "-",
  ]
    .filter(Boolean)
    .join("\n");
};

const sendEmail = async (payload: DesignPartnerPayload) => {
  if (!RESEND_API_KEY || !RESEND_FROM) {
    return { skipped: true };
  }

  const response = await fetch("https://api.resend.com/emails", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${RESEND_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      from: RESEND_FROM,
      to: [CONTACT_TO_EMAIL],
      subject: `New design partner application from ${payload.fullName}`,
      text: buildEmailText(payload),
    }),
  });

  if (!response.ok) {
    const errorText = await response.text();
    throw new Error(errorText || "Email delivery failed.");
  }

  return { skipped: false };
};

export async function POST(request: Request) {
  let payload: DesignPartnerPayload;

  try {
    payload = (await request.json()) as DesignPartnerPayload;
  } catch {
    return NextResponse.json({ error: "Invalid request body." }, { status: 400 });
  }

  const sanitized: DesignPartnerPayload = {
    fullName: String(payload.fullName || "").trim(),
    studioName: String(payload.studioName || "").trim(),
    city: String(payload.city || "").trim(),
    projectType: String(payload.projectType || "").trim(),
    email: String(payload.email || "").trim(),
    phone: String(payload.phone || "").trim(),
    moodBoardUrl: String(payload.moodBoardUrl || "").trim(),
    message: String(payload.message || "").trim(),
  };

  if (!sanitized.fullName || !sanitized.email || !sanitized.phone || !sanitized.city) {
    return NextResponse.json(
      { error: "Please fill in your name, city, email, and phone number." },
      { status: 400 }
    );
  }

  if (!isValidEmail(sanitized.email)) {
    return NextResponse.json({ error: "Please provide a valid email address." }, { status: 400 });
  }

  if (!sanitized.projectType) {
    return NextResponse.json({ error: "Please select a project type." }, { status: 400 });
  }

  if (!SUPABASE_URL || !SUPABASE_SERVICE_ROLE_KEY) {
    return NextResponse.json(
      { error: "Supabase credentials are not configured on the server." },
      { status: 500 }
    );
  }

  const insertResponse = await fetch(`${SUPABASE_URL}/rest/v1/design_partner_applications`, {
    method: "POST",
    headers: {
      apikey: SUPABASE_SERVICE_ROLE_KEY,
      Authorization: `Bearer ${SUPABASE_SERVICE_ROLE_KEY}`,
      "Content-Type": "application/json",
      Prefer: "return=representation",
    },
    body: JSON.stringify({
      full_name: sanitized.fullName,
      studio_name: sanitized.studioName || null,
      city: sanitized.city,
      project_type: sanitized.projectType,
      email: sanitized.email,
      phone: sanitized.phone,
      mood_board_url: sanitized.moodBoardUrl || null,
      message: sanitized.message || null,
      user_agent: request.headers.get("user-agent"),
      ip_address: request.headers.get("x-forwarded-for"),
    }),
  });

  if (!insertResponse.ok) {
    const errorText = await insertResponse.text();
    return NextResponse.json(
      { error: "Could not save your application. Please try again.", details: errorText },
      { status: 500 }
    );
  }

  try {
    const emailResult = await sendEmail(sanitized);
    if (emailResult.skipped) {
      return NextResponse.json(
        { error: "Application saved, but email is not configured." },
        { status: 500 }
      );
    }
  } catch {
    return NextResponse.json(
      { error: "Application saved, but email delivery failed. Please check email settings." },
      { status: 500 }
    );
  }

  return NextResponse.json({ ok: true });
}
```

### Task 2: `CountUpNumber` shared component

**Files:**
- Create: `components/design-partners/CountUpNumber.tsx`

**Interfaces:**
- Produces: `export default function CountUpNumber({ target, suffix, className }: { target: number; suffix?: string; className?: string })` — a client component that renders a `<span>` showing `0`, then animates up to `target` once it scrolls into view, respecting `prefers-reduced-motion`. Task 3 consumes this directly.

- [ ] **Step 1: Write the component**

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { animate, useInView, useReducedMotion } from "framer-motion";

type CountUpNumberProps = {
  target: number;
  suffix?: string;
  className?: string;
};

const CountUpNumber = ({ target, suffix = "", className }: CountUpNumberProps) => {
  const ref = useRef<HTMLSpanElement>(null);
  const isInView = useInView(ref, { once: true, amount: 0.6 });
  const shouldReduceMotion = useReducedMotion();
  const [displayValue, setDisplayValue] = useState(0);

  useEffect(() => {
    if (!isInView) return;

    if (shouldReduceMotion) {
      setDisplayValue(target);
      return;
    }

    const controls = animate(0, target, {
      duration: 1.4,
      ease: "easeOut",
      onUpdate: (latest) => setDisplayValue(Math.round(latest)),
    });

    return () => controls.stop();
  }, [isInView, shouldReduceMotion, target]);

  return (
    <span ref={ref} className={className}>
      {displayValue}
      {suffix}
    </span>
  );
};

export default CountUpNumber;
```

"use client";

import React, { useRef, useState, useEffect } from "react";
import { ChevronDown } from "lucide-react";
import ImageUpload from "@/components/custom-order/ImageUpload";

type DesignPartnerFormProps = {
  className?: string;
};

const PROJECT_TYPE_OPTIONS = [
  "Residential",
  "Commercial / Office",
  "Hospitality",
  "Retail",
  "Mixed-Use",
  "Other",
];

const DesignPartnerForm = ({ className }: DesignPartnerFormProps) => {
  const [status, setStatus] = useState<"idle" | "submitting" | "success" | "error">("idle");
  const [errorMessage, setErrorMessage] = useState("");

  const [projectType, setProjectType] = useState("");
  const [openDropdown, setOpenDropdown] = useState<"projectType" | null>(null);
  const [moodBoardUrl, setMoodBoardUrl] = useState("");

  const projectTypeRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const handleClickOutside = (event: MouseEvent) => {
      if (projectTypeRef.current && !projectTypeRef.current.contains(event.target as Node)) {
        setOpenDropdown(null);
      }
    };
    document.addEventListener("mousedown", handleClickOutside);
    return () => document.removeEventListener("mousedown", handleClickOutside);
  }, []);

  const handleSubmit = async (event: React.FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    if (!projectType) {
      setErrorMessage("Please select a project type.");
      setStatus("error");
      return;
    }

    setStatus("submitting");
    setErrorMessage("");

    const form = event.currentTarget;
    const formData = new FormData(form);
    const payload = {
      fullName: String(formData.get("fullName") ?? "").trim(),
      studioName: String(formData.get("studioName") ?? "").trim(),
      city: String(formData.get("city") ?? "").trim(),
      projectType,
      email: String(formData.get("email") ?? "").trim(),
      phone: String(formData.get("phone") ?? "").trim(),
      moodBoardUrl,
      message: String(formData.get("message") ?? "").trim(),
    };

    try {
      const response = await fetch("/api/design-partners", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(payload),
      });

      if (!response.ok) {
        const data = await response.json().catch(() => null);
        throw new Error(data?.error ?? "We could not submit your application. Please try again.");
      }

      setStatus("success");
      setProjectType("");
      setMoodBoardUrl("");
      form.reset();
    } catch (error) {
      setStatus("error");
      setErrorMessage(
        error instanceof Error ? error.message : "We could not submit your application."
      );
    }
  };

  return (
    <form
      id="apply"
      className={`grid grid-cols-1 gap-6 rounded-[24px] border border-black/10 bg-[#faf8f4] p-6 md:grid-cols-2 md:gap-8 md:p-8 ${
        className ?? ""
      }`}
      onSubmit={handleSubmit}
    >
      <label className="flex flex-col gap-2 text-[14px] font-medium text-[#313131]">
        Name
        <input
          type="text"
          name="fullName"
          placeholder="Enter your name"
          required
          className="min-h-[48px] w-full rounded-[12px] border border-black/10 bg-white px-4 text-[15px] text-[#1a1a1a] outline-none transition-all duration-200 focus:border-[#1a1a1a] focus:ring-1 focus:ring-[#1a1a1a]/5"
        />
      </label>
      <label className="flex flex-col gap-2 text-[14px] font-medium text-[#313131]">
        Studio / Firm Name
        <input
          type="text"
          name="studioName"
          placeholder="Your studio or firm"
          className="min-h-[48px] w-full rounded-[12px] border border-black/10 bg-white px-4 text-[15px] text-[#1a1a1a] outline-none transition-all duration-200 focus:border-[#1a1a1a] focus:ring-1 focus:ring-[#1a1a1a]/5"
        />
      </label>
      <label className="flex flex-col gap-2 text-[14px] font-medium text-[#313131]">
        City
        <input
          type="text"
          name="city"
          placeholder="e.g. Mumbai"
          required
          className="min-h-[48px] w-full rounded-[12px] border border-black/10 bg-white px-4 text-[15px] text-[#1a1a1a] outline-none transition-all duration-200 focus:border-[#1a1a1a] focus:ring-1 focus:ring-[#1a1a1a]/5"
        />
      </label>

      <div className="flex flex-col gap-2 text-[14px] font-medium text-[#313131]" ref={projectTypeRef}>
        Project Type
        <div className="relative">
          <button
            type="button"
            onClick={() => setOpenDropdown(openDropdown === "projectType" ? null : "projectType")}
            className={`flex min-h-[48px] w-full items-center justify-between rounded-[12px] border bg-white px-4 text-[15px] transition-all duration-200 outline-none ${
              openDropdown === "projectType" ? "border-[#1a1a1a] ring-1 ring-[#1a1a1a]/5" : "border-black/10"
            }`}
          >
            <span className={projectType ? "text-[#1a1a1a]" : "text-[#1a1a1a]/40"}>
              {projectType || "Select project type"}
            </span>
            <ChevronDown
              className={`h-4 w-4 text-[#313131]/60 transition-transform duration-200 ${
                openDropdown === "projectType" ? "rotate-180" : ""
              }`}
            />
          </button>

          {openDropdown === "projectType" && (
            <div className="absolute left-0 top-full z-50 mt-2 w-full rounded-[12px] border border-black/10 bg-[#faf8f4] p-2 shadow-[0_18px_35px_rgba(0,0,0,0.08)]">
              {PROJECT_TYPE_OPTIONS.map((option) => (
                <button
                  key={option}
                  type="button"
                  onClick={() => {
                    setProjectType(option);
                    setOpenDropdown(null);
                  }}
                  className={`block w-full rounded-[8px] px-3 py-2 text-left text-[14px] font-medium transition-colors ${
                    projectType === option
                      ? "bg-[#1f1f1f] text-white"
                      : "text-[#333333] hover:bg-black/5 hover:text-black"
                  }`}
                >
                  {option}
                </button>
              ))}
            </div>
          )}
        </div>
      </div>

      <label className="flex flex-col gap-2 text-[14px] font-medium text-[#313131]">
        Email Address
        <input
          type="email"
          name="email"
          placeholder="you@studio.com"
          required
          className="min-h-[48px] w-full rounded-[12px] border border-black/10 bg-white px-4 text-[15px] text-[#1a1a1a] outline-none transition-all duration-200 focus:border-[#1a1a1a] focus:ring-1 focus:ring-[#1a1a1a]/5"
        />

          type="tel"
          name="phone"
